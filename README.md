# AppVpn TV

VPN-клиент для телевизоров и приставок на Android TV 8 и новее. Здесь лежат только готовые сборки.
Для телефона есть [AppVpn для Android](https://github.com/jojobommm-dot/appvpn-android-releases).

## Установка

Проще всего через бесплатное приложение **Downloader** (от AFTVnews) из Google Play на телевизоре:

1. Установите Downloader и откройте его. Разрешите ему устанавливать приложения, когда телевизор
   спросит (или в «Настройки → Приложения → Безопасность → Неизвестные источники» включите Downloader).
2. Введите адрес и нажмите «Go»:

   ```
   github.com/jojobommm-dot/appvpn-android-tv-releases/releases/latest/download/appvpn-tv.apk
   ```

3. Когда файл скачается, нажмите «Установить». Если «Play Защита» остановит установку —
   «Подробнее» → «Все равно установить».

Можно и с компьютера: скачайте `appvpn-tv.apk` из [последнего выпуска](https://github.com/jojobommm-dot/appvpn-android-tv-releases/releases/latest),
включите на телевизоре «Отладку по сети» и выполните `adb connect <IP телевизора>` и `adb install appvpn-tv.apk`.

## Первый запуск

1. «Серверы» → «С телефона». Телевизор покажет QR-код.
2. Подключите телефон к той же Wi-Fi сети, наведите на код камеру и откройте ссылку.
3. Вставьте на открывшейся странице ссылку на сервер или адрес подписки, который вам прислали,
   и нажмите «Отправить на телевизор».
4. На «Главной» нажмите большую кнопку и разрешите подключение VPN.

Пульт: «Назад» переводит в меню слева, удержание OK на сервере — «Проверить», «Переименовать», «Удалить».

## Обновления

Приложение само проверяет новые версии; когда выйдет новая, на «Главной» появится «Обновить».
В первый раз телевизор попросит разрешить установку из AppVpn TV — разрешите и нажмите «Обновить» ещё раз.

## Что умеет

- Протоколы VLESS, Trojan, Hysteria2, TUIC и AmneziaWG 3.1.
- Российские сайты открываются напрямую, мимо VPN (можно выключить в «Настройках»).
- Выбранные приложения ходят в интернет без VPN («Приложения»).
- Подключение при включении телевизора.

## Если что-то не так

- **Нет окна разрешения VPN** (бывает на некоторых телевизорах): с компьютера
  `adb shell appops set ru.appvpn.tv ACTIVATE_VPN allow`.
- **Постоянная VPN** (интернет только через VPN), если в настройках телевизора нет раздела VPN:
  `adb shell settings put secure always_on_vpn_app ru.appvpn.tv` и
  `adb shell settings put secure always_on_vpn_lockdown 1`.
